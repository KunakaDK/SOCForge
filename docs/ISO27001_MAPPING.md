# ISO/IEC 27001:2022 learning crosswalk

This document is an educational mapping to help structure evidence in a student portfolio. It is not an audit, certification, legal interpretation or declaration of conformity.

| SOCForge evidence area | Related ISO/IEC 27001:2022 Annex A topic (illustrative) |
|---|---|
| Asset inventory and vulnerability records | A.5.9 Inventory of information and other associated assets; A.8.8 Management of technical vulnerabilities |
| Access roles and analyst workflow | A.5.15 Access control; A.5.16 Identity management; A.5.18 Access rights |
| Security event collection and review | A.8.15 Logging; A.8.16 Monitoring activities |
| Incident runbooks and case records | A.5.24 Information security incident management planning and preparation; A.5.25 Assessment and decision on information security events; A.5.26 Response to information security incidents |
| Secure configuration and change validation | A.8.9 Configuration management; A.8.32 Change management |
| Audit evidence and retention | A.5.28 Collection of evidence; A.8.15 Logging |

Organisations determine applicability through risk assessment and a Statement of Applicability. A portfolio demonstration does not establish that an organisation has implemented or passed ISO/IEC 27001.
